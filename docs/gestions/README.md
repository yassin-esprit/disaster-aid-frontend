# Documentation des Gestions

Ce dossier centralise la documentation fonctionnelle et technique de chaque gestion implementee.

## Gestions disponibles
- Resource & Shelter:
  - docs/gestions/resource-shelter/README.md
- Reviews & Trust:
  - docs/gestions/reviews-trust/README.md

## Utilisation recommandee
1. Lire le README de la gestion cible.
2. Verifier les routes frontend associees.
3. Verifier les endpoints backend utilises.
4. Executer la checklist de validation avant demo/livraison.

## Prerequis globaux
- Backend Spring Boot lance sur le port 8090.
- Frontend Angular lance localement.

## Commandes utiles
Backend:
- .\mvnw.cmd spring-boot:run

Frontend:
- npm install
- npm run start
- npm run build
